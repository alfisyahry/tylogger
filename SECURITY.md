# Security reporting

This early public release has not completed a comprehensive security assessment.
Do not use public issues for credentials, private logs, exploitable vulnerability details
or personal data. GitHub private vulnerability reporting is the intended contact route:

https://github.com/alfisyahry/tylogger/security/advisories/new

The link is usable when private vulnerability reporting is enabled for this repository.
If GitHub does not offer the private form, do not post the sensitive details publicly;
use a public issue only to request that the maintainer enable the private reporting channel.
There is no guaranteed response time or security-support lifecycle yet.
Treat external executables/plugins as trusted code running under your user account.
