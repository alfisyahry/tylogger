# Contributing

Use a focused branch and explain the problem, the change and the checks performed.
Preserve the native Rust/Win32 architecture, existing licenses and read-only source-log handling.
Use the pinned toolchain and run the commands in README.md. Add tests for changed behavior.
Report GUI, operating-system and network checks separately from synthetic tests.
Do not submit credentials, production logs, personal data or local development profiles.
New contributions are made under the repository's MIT license.
