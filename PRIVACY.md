# Privacy and local data

Tylogger reads user-selected logs and may retain configuration, bookmarks, sessions,
workspace paths, caches and generated reports. Logs and reports may themselves contain
credentials, personal information or server identifiers; review them before sharing.
Configuration code selects a user-profile directory or a portable config folder.
Backup that data before testing updates. Deleting a program does not necessarily remove it.

The local-file core does not require a hosted service. This is not a certification that
every code path or extension is free from network access. External tools and executable
plugins may launch processes and access files or networks with the current user's permissions.
Remote-source interfaces exist, but a live production SSH/SFTP implementation has not been
validated for this public snapshot. Do not enter production credentials for testing.
No telemetry collection service is configured or advertised by this project.
Public GitHub contributions, issues and downloads are subject to GitHub's own policies.
